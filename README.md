# HFCU Reengineering Prototype

Standalone static prototype for HFCU service reengineering.

## MVP modules

- Waiting status checker: member request lookup, queue stage, ETA, documents, notary, and support tabs.
- Remote notarization: document type selection, eligibility status, verification checklist, session scheduling, and receipt flow.

## Files

- `index.html` - prototype structure
- `styles.css` - app-style visual system
- `script.js` - mock status, notarization, and tab interactions

Open `index.html` in a browser to view the prototype.
